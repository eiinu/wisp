# Wisp

Wisp 是运行在自己电脑上的个人 Agent 工作台。通过对话调用模型、处理授权目录中的文件，并在同一界面浏览网页与文档。任务由本机 Host 执行，模型请求直接发送到你配置的 API 服务。

## 主要功能

- **对话与项目**：流式回复、历史恢复、归档与恢复；项目关联本地文件夹，项目下的对话继承目录权限，支持折叠和重命名。
- **工具调用**：按任务、轮次与调用展示执行过程，支持取消、审批和错误反馈。可浏览、读取、搜索文件，定点修改或写入文本，创建目录、移动和重命名文件，以及在受支持的桌面系统中移入废纸篓。文件变更需审批。
- **本地 MCP**：可在对话中经审批注册已有服务，或安装公共 npm 精确版本（需 Node/npm 12+、不执行安装脚本），再单独确认激活；设置页维护标准 stdio 服务、环境变量、禁用及工具列表；主对话可发现并调用已激活工具，每次调用均需审批。服务默认禁用，不内置 MCP。
- **网页工具**：请求在右侧打开网页；列出当前会话的预览标签，再按指定标签读取网页正文、标题与链接。列标签和读取无需审批，打开网页仍需确认。
- **浏览工作区**：网页与文件统一多标签，支持拖拽调整分栏；桌面版提供地址栏、前进后退、刷新和下载管理。
- **内容阅读**：文本、Markdown 和图片预览；对话与 Markdown 共用数学公式、代码高亮、表格和列表渲染，链接确认后在右侧打开。
- **模型设置**：独立设置页配置 DeepSeek 或 OpenAI 兼容 Chat Completions 服务；桌面版可通过系统安全存储加密保存 DeepSeek 官方 API Key。

## 支持范围

生产目标为 Electron 桌面端，当前提供 macOS Apple Silicon（arm64）DMG 构建。安装包目前未签名、未公证。

纯 Web 仅用于 UI 展示和截图验证，不是生产版本，不要求功能与桌面端对等。明确标注的界面样例不能代替真实 Host/Electron 功能验收。

内置文件工具仅操作明确授权的目录，不提供任意命令执行。用户激活的第三方 MCP 进程使用本机系统权限，不受项目目录限制。网页正文读取不等于自动操作网页。
