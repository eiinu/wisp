# 对话归档

侧栏每个对话旁的归档按钮将对话从常规列表移到「归档对话」。归档不是删除：完整消息、执行记录、项目归属和目录授权均保留在本机。归档列表提供恢复按钮；项目对话恢复后仍属于原项目，并展开该项目。没有永久删除操作。

归档当前对话时，仅选择同一项目的其他未归档对话；独立对话仅选择其他独立对话。没有符合条件的对话时显示空白，不切换到另一个项目。恢复不会擅自切换当前对话。

Host 验证会话状态：运行或等待审批期间禁止归档，不隐式取消任务。归档会话必须先恢复才能继续发送、执行工具或访问文件。恢复不会增加权限，文件写入仍需逐次审批。旧状态文件缺省为未归档，`archivedAt` 随会话元数据持久化；目录权限继续由可信项目记录派生。

验证覆盖普通/项目会话、重启与历史保留、归档幂等、跨项目选择边界、伪造归属字段、审批期间拒绝归档、恢复后的写入审批与拒绝无副作用。Web QA 页面只使用明确标注的内存样例，不访问真实目录或模型。
