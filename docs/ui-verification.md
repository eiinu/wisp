# 工作台 UI 验证

自动化命令：`pnpm typecheck`、`pnpm test`、`pnpm build`、`pnpm web:build`。UI DOM 测试使用 jsdom，它不进行真实布局或截图验收。Host 文件测试使用临时授权目录和实际文件，不访问用户目录或收费模型。

当前自动化覆盖：

- CommonMark/GFM、未闭合流式内容、组件/remark/rehype 扩展、安全链接/HTML/图片边界。
- txt 保持原文、md 渲染、UTF-8 与 BOM UTF-16、解码失败、空文件、2 MB 读取限制和 100,000 字符显示截断。
- 面板加载、错误、切换文件与会话时丢弃过期响应，写入仍提交审批。
- 对话草稿的会话隔离、流式 Markdown、无模型时 Enter 不发送、审批防重复提交。
- 弹窗焦点限制/Escape、配置中不响应新建会话快捷键、旧快照不能恢复已断开的连接。
- 用户向上阅读时不自动滚到底部；“回到最新消息”恢复跟随。

## 浏览器视觉验收清单

在可用浏览器打开真实构建，分别以桌面与窄屏尺寸检查：侧栏、首页、设置与连接弹窗、文件/网页面板、长消息/代码/表格是否溢出、输入框与审批是否可操作。

静态 Web 构建本身没有 Host，不应伪造已连接状态、会话或工具输出。静态走查只能验证相应可见界面。完整流程需在本机运行 `pnpm web:simulate`，使用页面显式标记的开发模拟模式验证真实 Host 与临时文件；该模式不代表真实模型 API 验收。当前云环境无可用受支持浏览器，视觉检查需另行完成；自动化测试通过不等于视觉验收通过。

## 静态浏览器走查记录

第 4 版 Web 构建在受支持云浏览器完成静态检查：设置初始焦点、双向 Tab 循环、Escape 恢复焦点，右侧面板切换/关闭，断开时操作禁用和页面无横向溢出均通过。1180×757 下发现设置滚到底部后标题和关闭按钮移出视区；已将标题栏与独立滚动的内容区域分离，待新构建复测。静态包不能端到端验证会话 Markdown 和真实 txt/md 文件预览，相关限制继续保留。
