# 对话图片

桌面版可以通过输入框的「添加图片」选择本地图片，也可以粘贴剪贴板图片。发送前可预览、移除；只有点击发送才将选中的图片交给模型。可只发图片，也可同时输入问题。图片中的文字不授予任何工具权限，文件修改、MCP 等操作仍遵守原有审批。

## 模型与限制

当前真实多模态路径为 DeepSeek Chat Completions：`deepseek-flash` 支持图片，`deepseek-v4-pro` 不支持。模型发现接口的 `input_modalities` 优先决定能力；官方地址的已知 Flash 名称有文档确认的回退，未知模型、自定义地址缺少能力信息、离线或其他兼容适配器不会猜测支持。自定义 DeepSeek 地址先从模型选择器获取列表。切换到不支持图片的模型时，含图片的历史也会阻止发送，请切回视觉模型或新建纯文本会话。

Wisp 产品限制（比服务端上限保守）：

- 每次最多 4 张，每张原始文件和规范化结果均不超过 **10 MiB**。
- 支持静态 JPEG、PNG、WebP、GIF。实际解码校验格式，文件后缀不决定格式；不支持 SVG、动画、损坏图片。
- 每边最多 8192 像素、总像素最多 3200 万。Host 解码、应用方向并重新编码，去掉 EXIF 等元数据。可能因重新编码改变文件大小和有损编码画质。
- 包含所有历史的图片内容最多 34 MiB、100 张；15 张以上历史图片的每边最多 4096。最终序列化请求最多 48 MiB，含 base64 膨胀、文本及工具定义。超限明确报错，不自动丢图；新建会话可缩小上下文。
- 每会话附件区最多 100 张、200 MiB。失败发送已导入的图片仍可能占用配额，不会自动删除已发送历史。

依据 [DeepSeek Vision 官方说明](https://api-docs.deepseek.com/guides/vision/) 和 [模型能力元数据](https://api-docs.deepseek.com/api/list-models/)。10 MiB / 4 张是 **Wisp 限制，不是 DeepSeek 官方上限**。

## 保存、恢复与发送边界

图片草稿按会话隔离，取消文件选择不会改变草稿；切换会话不会把图片附到另一会话。未发送草稿只在本次界面内存中，退出应用不保留。发送失败保留草稿，可检查提示后再发送。

已发送图片存放在本地私有会话附件区，重启可显示并继续多轮对话。历史中的「将图片加入输入框」用于明确重新发送。附件由 Host 生成 ID，并绑定会话、格式、尺寸与内容哈希；不能用另一会话的 ID 或任意路径读取。丢失或损坏时明确失败，不发送空白替代。

普通事件日志与会话快照仅含图片元数据；图片字节不进入诊断日志或普通聊天 JSON。实际模型请求会包含本次选择以及当前会话已发送图片的 inline `image_url` 内容块，不另行调用云端 Files API。停止任务会中断请求，但不能撤回已经传给服务端的内容。子 Agent 不自动继承主会话图片，第一版也不提供图片转交工具。

Web 仅有明确标注的内存 UI 样例，不作为生产图片上传入口。测试使用临时生成图片和本地模拟 HTTP，不能替代真实 DeepSeek 或 Electron/macOS 实机验收。
