> 用简洁的中文回答。解释新概念时，先给一个具体例子，再说明原理。

点击「保存助手设定」后，对所有对话的下一次任务生效。最多 12000 字符，支持多行。点击「清空设定」后仍需保存，才会恢复默认行为。切换设置分类会保留草稿；取消并返回时，未保存的更改需要确认放弃。

## 生效与保存

- 本地保存，重启后恢复；不需要模型已配置，也不会因保存发起模型请求。
- 每次任务开始固定一份设定，后续工具调用和模型续答保持不变。任务运行时可以修改，当前任务不受影响。
- DeepSeek 与 OpenAI 兼容接口均会随请求收到设定；离线验证模式不生成模型回答，不模拟个性化效果。
- 设定不作为用户消息插入，不修改聊天历史或历史执行日志。清空后，模型仍可能根据原有聊天内容延续之前的表达风格。
- 设定以普通本地配置保存，不是秘密保险箱。请勿填写密码、API Key 或其他秘密；发送任务时，设定会传给你配置的模型服务。

## 权限边界

助手设定与应用固定规则分开保存和组装，优先级低于应用规则，只用于个性化对话。它不授予文件、网页或 MCP 权限，不改变工具列表和审批；即使填写「跳过审批」，Host 仍按真实操作规则校验。模型遵循表达偏好的程度取决于所选模型，不构成权限控制保证。

此版本仅提供全局设定，没有项目级覆盖、角色切换或模板库。生产能力以 Electron 桌面端为准，Web QA 只提供明确标注的内存设置演示。
