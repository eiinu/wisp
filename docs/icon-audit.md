# 界面图标审计

本次检索 UI TSX 中的 SVG、文本字形、按钮图标槽，以及样式的伪元素定义。

- 原共享 SVG 的十个名称均有路径定义；未发现缺失的 SVG 名称。新增类型受 TypeScript 约束，并用注册表测试验证每项绘制路径。
- 项目折叠箭头原为 `›` / `⌄` 文本，布局依赖字体基线，展开与收起两种字形的视觉中心不同。改用同一个 SVG，在中心旋转；图标统一固定方形、block、不收缩，控制槽按中心对齐，不用位移补丁。
- 侧栏、设置、工作区开关、欢迎入口、批准、完成、输入发送/停止、错误关闭、上级目录、目录箭头原含 Unicode 符号。改为共享 SVG，避免不同字体缺字或字形差异；代码/消息复制也复用同一图标。已有网页导航、下载、标签关闭/新增继续用同一组件。
- 细分隔线、运行脉冲及连接状态点是 CSS 形状，保留；窄窗口的「返回对话」伪元素是文本标签。品牌字母、键盘快捷键和密码掩码不是图标，保留。
- 控件的可访问名称由按钮文本或 aria-label 提供，SVG 为装饰性内容。移动端隐藏文字不会隐藏 SVG，禁用按钮仍保留图标。

`qa.html` 提供完整图标集及禁用态，使用真实组件。DOM/源码回归覆盖名称、路径、视框、颜色继承、装饰性标记及折叠旋转规则；最终像素对齐仍需浏览器视觉验收，不能用 DOM 测试代替 Electron 原生验收。
