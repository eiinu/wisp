# 本地 MCP

Wisp 桌面端支持用户自定义的标准 **stdio MCP 工具服务**。设置 → 本地 MCP 中添加名称、可执行文件、JSON 参数数组和可选的绝对工作目录。例如已自行安装的 Node 服务可填 `node`，参数 `["/absolute/path/server.js"]`。不是 shell 命令文本；参数逐项传给进程，不通过 shell 拼接。应用从 Dock 启动时 PATH 可能不同，找不到程序请使用绝对路径。

## 管理与权限

- 新建/编辑后禁用，重启后也禁用；明确“信任并激活”才启动。没有内置服务，没有自动安装或自动重启。
- 激活后初始化、分页发现工具，展示状态与工具列表；支持服务的 `notifications/tools/list_changed` 和手动刷新。编辑、禁用、删除会停止旧连接并撤下工具，需重新激活。
- 第三方进程以用户系统权限执行，**不受 Wisp 项目目录权限限制**。工作目录不是沙箱。只运行信任的程序；激活本身就允许程序运行，不能等同于工具调用审批。
- 所有第三方工具调用都需单次审批，包括声明 `readOnlyHint` 的工具。审批绑定参数、连接与工具列表版本；列表变更、断开或禁用后旧审批不能调用新的服务。
- 取消/超时通知服务并关闭连接；禁用会取消正在使用此服务的任务（含待审批调用）。无法撤销已完成副作用，不自动重试调用。SDK 关闭 stdin，随后必要时 TERM/KILL 直接子进程；不承诺终止第三方程序自行脱离的守护进程。
- 配置是应用级，已激活工具可供各会话使用；工具执行事件、审批和结果仍归属于发起会话。它不是每项目隔离的 MCP 进程。

## 环境变量与持久化

非敏感配置保存在本机 `mcp-servers.json`；变量仅记录名称和保存方式。敏感值请放环境变量，不放命令、参数、名称或目录。

环境变量默认使用 Electron `safeStorage` 加密，按服务 ID 分开保存，并与启动命令、参数、工作目录绑定。无配置、无环境变量时不访问钥匙串。只在激活需要读取或用户选择保存时解密/加密；不可用则报错，**不会明文降级**。可主动取消勾选，选择仅当前 Host 会话保存；重启后需重新填写。编辑时不回显旧值，勾选替换会替换全部变量，空列表清除；修改命令时不能静默转交旧秘密。

删除会清除该服务持久化凭据及内存配置。秘密不进入 Renderer 快照、模型工具定义或普通事件日志；已知原值会从服务文本结果中替换，stderr 被丢弃。无法保证恶意服务不编码或自行联网泄露它取得的秘密，审批及脱敏不是对第三方程序的隔离措施。默认只继承 SDK 的最小系统环境，不继承 Wisp 模型 Key。

## 工具与限制

服务 UUID + 原始工具名摘要组成稳定模型工具名，界面显示服务名与原工具名。每轮模型请求重新取得当前可用列表，服务提供的描述/schema/结果均不可信。参数先按 JSON Schema 校验；服务返回 `isError`、协议失败、超时均作为失败交回模型，不伪造成功。

当前上限：16 个配置、每服务 64 个工具、激活工具总计 96 个；schema 16KB、参数 32KB、stdio 单条协议帧 1MB、结果正文 32K 字符；发现和调用默认 10 秒。结果含截断标志。支持文本、嵌入文本资源与结构化结果；图片/音频/二进制仅返回省略标记，不自动打开链接。支持 JSON Schema 2020-12 及显式 Draft-07；不能解析的 schema/外部引用会连接失败，不联网加载 schema。首版不支持远程 HTTP/OAuth、资源订阅、prompts、sampling、elicitation 或持久化长任务扩展；不承诺兼容非标准服务器。

纯 Web 只供 UI 验证。`qa.html` → 工作台样例 → 设置 → 本地 MCP 提供明确标注的内存管理场景；命令填写 `fail` 可观察模拟启动失败。它不执行命令、不持久化秘密，不是桌面验收。

## 验证

测试使用官方 SDK 离线协议夹具及临时 stdio 子进程，并通过本机模拟 DeepSeek HTTP/SSE 接口验证真实 adapter → Host → 审批 → MCP → 模型续答。安全存储测试使用假密码服务。实际 macOS 钥匙串、Dock 启动 PATH、任意第三方运行时及 GUI 生命周期仍需实机验收。

参考：官方 [MCP Tools 协议](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)、[stdio 传输](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)、[TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk)。当前固定 SDK 1.32.2。
