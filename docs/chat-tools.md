# 主对话工具调用

主对话的 `run.start` 经 Host Runtime 创建会话独立 Agent，向配置的模型发送当前可用工具 schema。DeepSeek adapter 聚合 SSE 工具参数及调用 ID；Host 顺序执行每批调用、逐项回填结果，再继续请求模型。任务默认最多 8 轮，取消或预算耗尽时停止。

当前文件工具为 `files_list`、`files_read`、`files_write`。只有明确授权工作目录或继承可信项目目录的会话才提供这些工具。路径和写入内容在审批前校验，执行时再次检查目录边界。写入仍须批准完整参数；一次审批不能重复使用。暂未增加全文搜索、任意 shell 或全盘访问。

未知工具、错误参数和执行错误作为带调用 ID 的错误结果回传模型；取消不会当作可继续的工具错误。模型能调整请求，但依然受相同步数预算限制。多个工具串行执行，避免副作用顺序不确定。已请求写入或浏览器工具的失败任务不能自动重试；用户必须检查结果并发送新指令。重启将未完成任务标为中断，不重放工具。

私有模型续传（含 DeepSeek reasoning）仅保存在 Host 私有会话数据中；事件日志与 Renderer 不接收原始推理。界面按调用 ID 显示工具状态，详情可查看参数和结果，成功读写的文件可通过原有授权预览接口打开。

浏览器预览并非 Agent 浏览器控制。只有显式连接成功的 Playwright MCP 才注册相应工具，仍逐次审批。本次没有在云端验证实际 Chromium 启动。

## 本地验证

`pnpm web:simulate` 启动明确标识的开发模拟模式，使用真实 DeepSeek adapter、Host 和文件工具，不调用外部模型。详情见现有模拟开发说明。新增协议场景：`[demo:multi]`（双工具）、`[demo:escape]`（路径越权）、`[demo:invalid]`（错误写入参数）、`[demo:loop]`（预算耗尽）。这些脚本场景只属于开发模拟服务，正式 provider 不匹配提示词来伪造执行。

`pnpm test` 中的 simulation 测试经受限本地 HTTP 接口覆盖读取、批准写入、拒绝无副作用、工具结果续答、取消、模型请求重试不重复写入、会话切换/重启和上述新增场景。项目与路径隔离由 projects/runtime 测试覆盖；adapter 测试覆盖交错 SSE、私有续传及错误边界。

`qa.html` 的工作台是明确标记的组件样例，审批只更新内存；不能替代真实 Host 或 Electron 实机验证。真实 DeepSeek API 未进行收费验证。
