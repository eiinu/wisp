# Wisp 界面规范

`tokens.css` 集中定义灰阶与语义色、字号/行高、间距、圆角、焦点、禁用态、阅读宽度及弹窗阴影。`reset.css` 保持低优先级基础层，组件样式消费共享变量。原有 Markdown 解析器残留样式与重复焦点处理已清理；不改 Host 协议或权限。

- 侧栏：紧凑会话行，选中背景覆盖整行；归档与项目重命名在鼠标悬停/键盘聚焦时显示，触屏始终显示。长名称保留省略与完整提示，不挤压操作区。
- 对话：统一阅读宽度与内容层次，轻灰用户消息，助手正文、工具详情、审批和复制操作采用一致灰阶。审批风险提示与实际错误完整保留。
- 输入：多行内容自动增高，上限 220px，短内容自动收回。目录标签可省略并提供完整路径提示；发送/停止保留稳定点击区域。同步锁防止快速重复发送，失败保留草稿，不抢占用户当前焦点。阅读旧消息时不强制回到底部。
- 工作区：保留全高多标签、44px 标签带与单工具栏；导航、文件、下载使用同一表面/边框/控件规范。拖拽范围、双侧最小宽度、比例记忆、原生视图遮挡和边界计算不变。
- 弹窗：统一标题/表单/主次操作，正文滚动、标题保持可达，窄宽度操作可换行。设置、授权与连接操作统一防重和处理中状态，异步操作完成前不通过 Escape/背景关闭，完成后恢复触发入口焦点。目录/凭据安全说明不隐藏。

`qa.html` 可切换「对话工作台样例」，渲染真实 App 组件但使用明示的内存 fixture。消息、审批、保存均是测试数据，不访问 Host/模型/真实文件，不得输入真实 Key。生产 `index.html` 不包含此 fixture。其他组件样例继续覆盖项目/归档/文件/网页/表单/图标/Markdown。

自动验证覆盖防重、失败草稿、多行高度、焦点恢复、滚动保持与样式边界。浏览器视觉验收需另行检查宽窄布局、hover/Tab/触屏可达性和弹窗；云端测试不等于 macOS Electron 原生验收。
